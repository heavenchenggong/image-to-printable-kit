# 可切换图案 / 可动机构（reveal-slider）设计模式

> 来源：MakerWorld「心情涟漪」可切换表情的拉链挂件 · 挂绳通用版 v3，
> 设计师 阿驴pp，BambuStudio 02.08.02.60 工程，2026-11-03 创建。
> 分析文件 `~/Downloads/挂绳版本v3.3mf`，4 件 / 3 色 / 3 盘，主体 20 × 50.5 mm。
> **本文件是逆向拆解后的可复用规范，不是那个模型的说明书。**

## 一、什么时候用这套模式

用户要的是「**一个能拨动、能切换内容、能挂起来、最好不用 AMS**」的小物件时，
直接套本模式，别从头想机构：徽章 / 钥匙扣 / 拉链挂件 / 状态牌 / 行李牌 /
桌面提示牌 / 可换图案的冰箱贴 / 儿童玩具拨动件 / 设备状态滑块。

判定关键词：拨动、切换、变脸、翻牌、滑动、可换图案、可换表情、免 AMS 多色、
能挂绳子、卡扣可拆。

不适用：需要旋转/齿轮/弹簧复位 → 另设计；需要单件一体打印的活动铰链 → 走
`print-in-place` 铰链（间隙 0.2–0.3mm），与本模式的分件叠装不同。

## 二、四层叠装（核心）

```
        ┌─────────────────────────────┐
  ④ 上盖 │ 圆形观察窗 + 拨杆长槽 + 装饰凹槽 │  ← 外观色 A（杏）
        │ 四周 4 处卡扣凸起；内腔朝下      │
        ├─────────────────────────────┤
  ③ 滑片 │ N 组图案（镂空）+ 侧面拨块       │  ← 主色 B（橙），**唯一需要重做的件**
        ├─────────────────────────────┤
  ② 衬片 │ 纯色薄平板，作图案背景 + 阻尼面   │  ← 对比色 C（黑）
        ├─────────────────────────────┤
  ① 底壳 │ 开口朝上的浅盘 + 一体挂耳        │  ← 外观色 A（杏）
        └─────────────────────────────┘
```

装配顺序固定 **底壳 → 衬片 → 滑片 → 上盖**，从下往上叠，压合四周卡扣。
拨块穿过上盖长槽露出来，手指沿槽上下拨 → 窗口下方依次经过滑片上的 N 组图案。

### 为什么图案要做「镂空 + 深色衬片」，而不是多色打印

镂空让下面的黑色衬片透出来形成图案 —— **一个单色件就能画出任意复杂图形**，
不需要 AMS、不需要换料、不需要层内换色。衬片同时兼任：
1. 图案背景（对比色）；
2. 滑片的**摩擦底面**（见第五节阻尼）；
3. 遮住底壳内部结构与卡扣，从窗口看进去是干净的黑底。

> 推论：把「内容」和「结构」彻底解耦。想换主题（表情/文字/图标/节日图案）
> **只重做第 ③ 件**，①②④ 与所有配合尺寸原封不动。这是本模式最值钱的一点。

## 三、实测几何（可直接当默认参数起步）

单位 mm。所有数值来自 3mf 网格逆向，非目测。

| 部位 | 实测 | 说明 |

| 外形 | 20.0 × 50.5，圆角长条 | 上盖 / 底壳同外框 |
| 上盖 ④ | 20 × 50.5 × 3.8，V=1290 | 内腔 15.44 × 42.25 |
| 底壳 ① | 20 × 50.5 × 5.4，V=4215 | 内腔 14.20 × 42.20 |

### 配合间隙链（每层只差 0.15–0.17 单边）

```
底壳内腔 14.20 ─ 衬片 13.90                 → 单边 0.15
上盖内腔 15.44 ─ 滑片 15.10                 → 单边 0.17
长槽宽   1.80  ─ 拨块宽 1.60                 → 单边 0.10
```
**XY 全部是滑配，没有任何过盈。** 这是 PLA 0.2mm 层高、2 墙、0.4 喷嘴下的稳妥值。

## 四、三条必须同时成立的等式（机构自洽判据）

设 `D_w` 窗口直径、`P` 相邻图案组间距、`T` 行程、
`L_s` 槽长、`L_k` 拨块长、`L_c` 腔长、`L_p` 滑片长：

```
① T = L_s − L_k        槽决定的行程       实测 18.15 − 5.64 = 12.51
② T = L_c − L_p        腔决定的可用滑动量  实测 42.25 − 29.60 = 12.65
③ P ≈ T ≈ D_w          图案间距≈行程≈窗径  实测 11.77 ≈ 12.51 ≈ 12.00
```

- ①≠② → 要么拨块还没到图案位就撞壁，要么滑片在腔里晃荡。
- ③ 的 `≈ D_w` 保证拨到一端时**上一组图案完全移出窗口**，不会露出半张脸。
  两态用 `P = T`；三态要 N 组图案，则 `T = (N−1)·P`。
- 窗口中心与图案组中心必须对齐（本例都在 x≈−1），窗口偏位是为了给长槽腾地方。
- **多一组图案很贵**：`L_p` 增加 P，`T` 也增加 P → `L_c = L_p + T` 一口气
  增加 **2P**，外形长要跟着加 2P。实测三态 / Ø16 窗口时腔长 82mm、
  外形需 ≥ 86.6mm，已经不是「小挂件」了。想多内容优先换滑片主题，
  别在同一件里堆状态数。

`scripts/reveal_slider.py` 把这三式做成算尺：给几个主参数，输出全套派生尺寸
并校验等式；不满足就报该改哪个量。**做新机构先跑它，别手算。**

## 五、阻尼来自 Z 向夹紧，不是 XY 过盈（最容易学错的一处）

作者的 11-03 更新记录原话：「**增加橙色层板厚度，增加 0.1mm，增加阻尼感，
减少可能出现的松动的问题**」。

即：XY 保持 0.15–0.17 滑配保证拨动顺手，**靠把滑片做厚 0.1mm 去压缩 Z 向
净空**，让上盖把它轻微压在衬片上，产生摩擦阻尼 —— 拨得动，但上下晃动不会自己滑下来。

- 这是**可调校的单一变量**：松 → 滑片 +0.1；涩 → −0.1。不要动 XY 间隙去调阻尼，
  一动就卡（参见 `modeling-pitfalls.md` #21/#22 的公差预算）。
- 衬片用 PLA 光面板，摩擦稳定；别用纹理面朝上。
- 别指望卡扣提供阻尼：卡扣只负责不掉件。

## 六、免 AMS 分色与分盘

`4 件 / 3 色 / 3 盘`，每盘单槽，单色机也能打：

| 盘 | 颜色 | 件 |
|---|---|---|
| 1 | 杏色 `#F7E6DE` | 底壳 + 上盖（两件同色同盘） |
| 2 | 橘橙 `#F99963` | 滑片 |
| 3 | 黑色 `#000000` | 衬片 |

颜色不是靠 `<basematerials>`（Bambu 不认），而是 `Metadata/model_settings.config`
里每个 object 的 `extruder` 槽位号（1-based → `filament_colour[index-1]`）。
本例：底壳/上盖 `extruder=6` → `#F7E6DE`，滑片 `=3` → `#F99963`，衬片 `=4` → `#000000`。

**分盘规则见 `split-to-print.md`**：一盘一色、全部锁 1 号槽。别把三色排一张床。

## 七、零支撑打印朝向

| 件 | build transform | 理由 |
|---|---|---|
| 上盖 ④ | 绕 X 翻 180°（`1 0 0 0 −1 0 0 0 −1`），装饰面**朝下贴板** | 内腔朝上变开放，无需支撑；外表面拿到 Textured PEI 颗粒质感 |
| 底壳 ① | 正常，开口朝上 | 浅盘天然自支撑 |
| 衬片 ② / 滑片 ③ | 平放 | 薄板，最稳 |

工程参数：`enable_support = 0`（整盘零支撑）、0.2mm 层高、2 墙、50% grid、
5 顶 / 3 底、`auto_brim 5mm`、Textured PEI、PLA 220℃/55℃、X2D 0.4 双喷嘴。
**装饰一律做浅凹槽不做凸起**，才能保持零支撑。

> 注意：装饰面朝下贴板时，浅凹槽由首层桥接形成。槽深控制在 ≤ 0.6mm、
> 槽宽 ≤ 2mm，超过会出现下垂/拉丝，届时宁可把件翻正常朝上并开支撑。

## 八、一体挂耳（「挂绳版本」的通用做法）

- 挂耳**与上盖、底壳一体打印**，不额外加五金；两件各带半个挂耳，叠装后合成一个
  更厚的耳朵（局部厚度翻倍，抗撕）。
- 穿孔做**扁椭圆 / 圆角长孔 6.8 × 2.8mm**，不是圆孔：扁孔适配织带宽度、
  长轴方向应力分散、绳结好打。
- 挂耳位于长轴一端、居中；孔边距 ≥ 1.8mm（本例 x 方向两侧各约 1.8mm）。
- 连接方式：短挂绳穿过原拉链头孔 + 挂耳孔，**绳结固定**，不用扣件、不用胶。
- **产品化思路**：主体机构不变，只换「连接接口」就衍生版本 —— 原版是
  专为某款羽绒服拉链做的卡口，v3 换成通用挂绳孔。以后做适配不同挂载方式
  （钥匙圈 / 背包织带 / 磁吸 / 别针）时，同样只改这一处。

## 九、卡扣与可拆装

4 处凸起卡扣分布四周，压合即装、可反复拆开换滑片。设计约束：
- 卡扣**只承担防脱**，不承担定位与阻尼；定位靠内腔四壁。
- 可拆装是本模式的前提：不能拆 = 不能换图案 = 内容定制的能力作废。
- 具体卡扣尺寸 / 应变核算走 `snap-fit.md`（含「必须先打配合校验件」纪律）。

# 乙式：Print-in-place 伸缩锥管（登山杖挂件）

> 来源：`可伸缩登山杖拉链挂饰.3mf`（蕉内×拓竹联名「攀过那座山」，Bambu P1S，2026-10）。
> 与甲式（滑块显隐）并列的第二种 print-in-place 机构。算尺：`scripts/telescoping_taper.py`。

## 一、什么时候用

要做一个**能拉长/收回的细长件**（伸缩天线、登山杖、教鞭、卷轴挂件），
又不想装配、不许有松脱风险。特征：多级**同锥度薄壁锥管**同心嵌套，
装配态即打印态，打印完成即可用。

## 二、五组件结构（本例实测）

全部同轴（轴心同一 xy 点），收合态下三管+内杆底端平齐、穿过手柄底开口：

| 件 | 角色 | 底端外/内 r (mm) | 顶端外/内 r | 壁厚 |
|---|---|---|---|---|
| 手柄筒 comp0 | 山体壳 + 底出口 + 顶盖 | 出口内缘 r 5.70–5.80 | — | — |
| 3 号锥管 comp3 | 最粗滑动管 | 5.00 / 4.20 | 5.75 / 4.95 | 0.80 |
| 2 号锥管 comp1 | 中管 | 3.50 / 2.70 | 4.25 / 3.45 | 0.80 |
| 内杆 comp2 | 细杆（底端球头导向） | 2.01 / 1.21 | 2.75 / 1.95 | 0.80 |
| 底裙 comp4 | 装饰收口环（高 3） | 内 5.70 / 外 7.12 | 同 | 1.4 |

锥度**全部一致**：半径差 0.75 mm / 管长 65 mm ≈ 0.66° 半锥角，底细顶粗。
管是直纹面：每管仅 2 圈顶点环（126 边 × 内外 2 环 × 上下 2 端 = 504 顶点），
面数极低，圆度误差 r(1−cos(π/126)) < 0.002 mm 可忽略。
内杆底端做**球冠导向头**：1 mm 内 19 个环从 r=0 平滑收到壁面（细节全在头部）。

## 三、两条公差法则（本机构的灵魂）

**法则 1：滑动间隙统一放大到单边 0.70。**
三级滑动面（comp0 出口−comp3、comp3 内−comp1、comp1 内−comp2）全部实测
单边 0.69–0.72 mm，且因锥度相同**全程恒定**。远大于常规滑配 0.3–0.5，
原因：a) 65 mm 超长配合，公差/翘曲沿长度积累；b) 锥管若有局部锥度偏差
即咬死，间隙是保险；c) 装饰挂件不要求刚性，牺牲手感换绝不卡死。

**法则 2：防脱 = 线-to-line 微干涉。**
每级管**顶端（全管最粗处）** 与下一级底端开口 0–0.05 mm 干涉，永远拉不脱：
- comp3 顶 r5.75 ↔ comp0 出口 r5.70–5.80（+底裙内孔 r5.70 双重阻挡）
- comp1 顶 r4.25 ↔ comp3 底孔 r4.20（+0.05）
- comp2 顶 r2.75 ↔ comp1 底孔 r2.70（+0.05）

行程上限由此决定（本例管顶撞到出口时 ≈62 mm）。收合定位由手柄内腔
z=+27 处的缩口台阶挡住管顶（管顶收合位 z=24.36，余 3 mm）。
⚠️ 复刻注意：0.05 干涉偏小，打印误差 ±0.1 可能让防脱失效（整管拉出脱扣）。
复刻建议把干涉加到 0.15–0.20，滑动间隙不动。

## 四、打印实现要点

- **竖立打印装配态**（本例 81 mm 高）：锥度使全件无 >45° 悬挑，
  手柄在上大端朝上，逐层放大；树支撑仅需手动点补山体凹谷。
- 壁厚 0.8 = 2 × 0.42 线宽：`wall_loops=2` 两道墙即实心壁，与设计咬合。
- 0.4 喷嘴 / 层高 0.16 / 8% gyroid / 顶 6 底 4 / seam aligned（细长件避免乱缝）。
- 0.16 层高不是精度需要，是**分层线在锥面上形成摩擦纹理**——刚好给
  0.7 间隙补一点阻尼；层级太光滑反而会"自由落体"。
- 作者原话：模型细长，劣质耗材层粘差易损坏 —— 细管壁是层粘敏感件，
  选层粘好的 PLA。

## 五、连接件体系（主体不动、换接口）

描述里"长环圆环 2 款回环连接拉链卡扣"实测对应 6 小件：

| 件 | 形状 | 用途 |
|---|---|---|
| obj_14 | 带山纹外框的素圆环+颈部 | 顶部装饰环座·圆环款，颈部插入手柄顶盖环槽 |
| obj_15 | 同外框+山形镂空图案 | 顶部装饰环座·图案款（蕉内款） |
| obj_4 | Ø28 螺旋开口卷环，厚 2.1 | 绕进拉链杆任意位置（钥匙圈式） |
| obj_9 | 17×37 跑道形搭接开口环，厚 2.1 | 掰开套拉链座，斜搭接面闭合 |
| obj_6 | 26×4.5 扁条+八边指扣 | 替换蕉内羽绒马甲的原厂拉链拉片 |
| obj_16 | Ø10×1 薄圆环 | 万能中间连接环 |

设计手法与甲式同源：**主体件一个不动，接口全部可换**——同一手柄
配两款装饰环座、四种挂接方案，SKU 靠小件扩展。渐变色耗材顺带掩盖
多件间的色差。
