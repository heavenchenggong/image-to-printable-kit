# 有机细枝雕塑：摆位、细节密度与最小可打印特征

> 来源：`Bowtruckle.3mf`（护树罗锅 /《神奇动物》皮克特，作者 LostHorcrux，MakerWorld
> Exclusive，CreationDate 2026-01-23，BambuStudio 02.03.01.51，X1C + 0.2 mm + 2 墙 +
> 15 % grid + tree(auto) 支撑）。
> 适用对象：树枝小人、藤蔓、珊瑚、骨骼、根须这类**体积极小而表面积巨大**的件。
> 和 `mechanisms.md`（甲/乙式）不是一类——这里没有机构，全部胜负在**摆位 + 最小特征 + 支撑**。

## 一、先量三个数，再决定怎么打

| 指标 | 本例实测 | 判据 |
|---|---|---|
| 体表比 S/V | 5 577 mm² / 3 754 mm³ = **1.49 /mm** | 同体积立方体只有 0.39。>1.0 即「细枝状」，任何按实心件调的填充/墙数都要重想 |
| 逐层截面总面积的量级 | 20–80 mm²（躯干 57，腿 22–29，最细 3.6） | 截面面积 ≈ 一根 Ø5–6 的杆。焊不焊接、支撑往哪打都由它决定 |
| 最细特征 | **0.4–0.7 mm**（指节、细枝、树皮沟） | 低于 2×线宽（0.84）→ 切片器会丢或只给一条单线 |

量法（可复用，几分钟出全套）：

```python
# 逐层截面 → shapely 环 → 等效直径 4A/P（近圆截面时 4A/P ≈ Ø）
S = segs_at(z)                                    # 三角面与水平面求交，见 pitfalls #21 配对法
polys = list(polygonize(unary_union([LineString(np.round(s,5)) for s in S])))
d = 4*p.area/p.length                             # 每个独立枝干
```

> ⚠️ **必须先 `unary_union` 再 `polygonize`**。端点虽然成对重合（可用 KD-tree 验证
> 100 % 配对），但浮点差 1e-5 就足以让 polygonize 判成「未闭合链」而**静默丢弃整条环**。
> 不 union 时本例截面总面积会从 50 mm² 掉到 0.4 mm²——**虚小一个数量级**，还不会报错。
> （和 pitfalls #21 的「空操作」是同一类失败：看起来跑通了，数字是假的。）

## 二、摆位：立姿建模、躺姿打印

作者把 99.8 mm 的立姿件放倒成 **43.3 mm 高、100 × 55 mm 占地**，只留两处贴板
（脚端 + 叶尖端，world z<0.6 的顶点全部集中在这两簇，中间悬空成拱）。

- **降高度**：细长件在 100 mm 高时是悬臂杆，喷嘴每层的拖拽都在放大晃动；
  43 mm 时同样的晃动被砍掉一半以上。
- **摊角度**：立姿时手臂、根须是接近水平的短悬臂；放倒后它们随身体转成浅角度，
  悬垂面积反而略降（实测朝下 >45° 的面积占比：作者位姿 13.2 %，立正 13.4 %，
  仰躺 14.2 %，侧躺 16.7 %）。
- **代价**：贴板那一侧的表面细节会被压平/贴死。本例是树皮纹理，损失可接受；
  如果贴板面是脸或图案，**别放倒**。

判定顺序：先按 `pose_brute.py` 排序候选姿态 → 挑「连续 ≥2 层无浮空 + 首层截面够大」的 →
再确认**贴板面不是关键外观面**。

## 三、细节密度：够用就行，过密是负担

本例 2 033 004 面 / 5 577 mm² = **365 面/mm²**，边长中位数 **0.085 mm**。
0.4 喷嘴能分辨的特征约 0.2 mm，也就是说**减面 4–6 倍不丢任何可打印特征**，
而文件 175 MB、Studio 打开和切片都变慢。

- 雕刻软件导出默认就是百万面级，**不要直接拿去切片**。
- 判断标准：`中位边长 ≤ 0.15 mm` 或 `面密度 ≈ 100 面/mm²` 就够；
  低于这个数只是让 STL 变大，不会让成品更细。
- 缩放的**下限由最小特征决定**：本例主体 Ø2.8–5.2 mm、最细 0.4–0.7 mm。
  缩 50 % → 腿变 1.4 mm（不到 2 道墙）、细节降到 0.2–0.35 mm，全在喷嘴宽度以下——
  不是「变细」，是**直接消失**。作者那句「不能缩小」是可算的：
  `要让特征成为实体墙，缩放系数 s ≥ 0.84 / 最细特征直径`，本例算出来是 **1.2–2.1**，
  也就是说 1× 已经在临界线以下，**只能原尺寸或放大**。

## 四、支撑四件套：一起调，单独调一个没用

| 参数 | 本例 | 作用 |
|---|---|---|
| `support_type` / `support_style` | tree(auto) / **tree_slim** | 细枝好掰，接触点小 |
| `tree_support_branch_diameter` | 2 mm | 再细会自己断在半空，再粗掰不动 |
| `support_top_z_distance` | 0.25 mm | 顶隙：小了不起毛边，大了粘死 |
| `support_object_xy_distance` | 0.35 mm | 侧隙：决定能不能「一掰整片掉」 |
| `support_threshold_angle` | 30° | 保守（多生成），配合上四项才敢这么设 |

作者原话是「设置确保树状支撑件超轻松移除」。**四件套是一个整体**：
只把枝径改细、顶隙不动，照样撕毛；只加顶隙、枝径粗，支撑会把自己从床上拔起来。

另外两条本例的隐含前提：
- `brim auto 5 mm` —— 躺姿只有两簇接触点，不抓板会被喷嘴带走。
- 顶壳 **5 层**（比默认多）—— 细枝的「顶面」其实是曲面最高点，顶壳不足会打出破洞/透光点。

## 五、参数起点（细枝雕塑，0.4 喷嘴）

```
layer 0.2 / 墙 2（0.42 线宽）/ 填充 15% grid / 顶壳 5 / 底壳 3
支撑 tree(auto)+tree_slim / 枝径 2 / 顶隙 0.25 / XY 0.35 / 阈值 30°
brim auto 5 mm   ·   seam aligned   ·   不检测薄壁（detect_thin_wall 0）
```
层高不必降到 0.12：细枝的分辨率在 XY，不在 Z；0.2 已经够，还能省一半时间。
`detect_thin_wall` 关着 = 树皮沟这类亚线宽细节会变成噪点，**要细节就靠几何做大，别指望切片器补**。

## 六、验收清单

- [ ] 体表比 >1.0 时，填充/墙数按「薄壁壳」而非「实心件」设
- [ ] 逐层截面量过：最细特征 ≥ 2×线宽（0.84 mm），否则放大模型
- [ ] 网格边长中位数 ≤0.15 mm 就够；超过 300 面/mm² 先减面
- [ ] 摆位确认贴板面不是关键外观面；两端着板时中间是否成拱（会不会变长桥）
- [ ] 支撑四件套同时给：类型 + 枝径 + 顶隙 + XY 距
- [ ] 躺姿/多接触点姿态必开 brim
- [ ] 顶壳 ≥4 层（细枝顶面容易破洞）
- [ ] 交付说明写清「能否缩放」的**倍数**，不要只写「不能缩小」
