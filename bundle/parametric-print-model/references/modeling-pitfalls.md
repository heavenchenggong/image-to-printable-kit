# 参数化建模与预览渲染的坑（modeling-pitfalls）

来源：heart-hood-plush（星星人爱心火苗，12 件胶接拆件）实战踩坑记录。
共同特征：**索引级检查全绿（watertight / euler=2 / bbox 正确），但实际是错的**。
每条都给「症状 → 根因 → 修法」。

## 1. 缩放函数的 k² 陷阱（最阴险）

```python
def head_ellipsoid(k):
    return ellipsoid(HEAD_LO_R * k, at, tuple(np.array(HEAD_LO_S) * k))
#                                            ^^^^ scale 也乘了 k = 实际放大 k²
```

- **症状**：脸片壳顶点超出理论椭球面 3.1mm；按解析式贴脸的五官整个埋进壳里，
  多视图渲染上一个都看不见；但 watertight / euler / bbox 全部正常。
- **根因**：`r` 是大小、`scale` 是形状（各轴比例）。两者都乘 k = 放大 k² 倍。
  解析式（`face_surface_y`）只按一次缩放算，几何却按两次走，差 (k²−k)×R。
- **修法**：缩放函数只缩放半径，**不缩放 scale**。写完必须做数值对账：
  `mesh.vertices.max(axis=0)` vs 解析式算出的理论极值，相等才收工。

## 2. matplotlib 3D 渲染：小件被大件盖住

- **症状**：Poly3DCollection 合并全部三角形后，眼睛/高光/小特征整个消失
  （它们几何上明明凸出在脸面前方 1.25mm）。
- **根因**：`Poly3DCollection` 的 `zsort='average'` 对跨件深度不可靠；
  `set_zsort('none')` 在部分 matplotlib 版本直接报错（`'none'` 不是合法值）。
- **修法**：**不用 3D collection，自己投影到 2D**：
  1. 相机基向量：`cam=(cos(elev)cos(azim), cos(elev)sin(azim), sin(elev))`，
     `r = normalize(cross([0,0,1], -cam))`，`u = cross(-cam, r)`
  2. 每三角形深度 `depth = -(mean(v) @ cam)`，**降序排**（`np.argsort(-depth)`，
     远的先画——升序会把近的排前面先画，结果大件盖小件）
  3. 顶点投 `sx = v @ r; sy = v @ u`，用 `PolyCollection` 按顺序 add_collection
- **flat shading**：每面 `lum = amb + d1*clip(n·L1) + d2*clip(n·L2)`，
  `facecolor = base * lum`，`shade=False`。无光照平涂是"廉价感"的主要来源。

## 3. 倾斜件与平面座配：只算一个方向会漏

- **症状**：心形整体前倾 12° 后，最低点比头顶平面低 1.9mm（过盈，装不进去）。
- **根因**：验算时只近似了 x 向的点。截断面是**圆**，圆上朝 +Y 的点在前倾时
  额外下沉 `r·sin(θ)`，比 x 向点多沉一倍。
- **修法**：竖直态建件时，把截断面**预倾 +θ**（绕座配球心/轴心反向旋转切刀），
  整体前倾 −θ 后截面恰好回正。回正后用 `mesh.bounds` 复算最低点 ≥ 座面。

## 4. 布尔内壳不要和外壳共面

- 差集内壳取 `1.00`（= 外壳半径）→ 重合面，引擎沿重合区吐近重复顶点
  （实测 25 个，全在重合环上），导出后按坐标合点的读取端全变 4 边面。
- 内壳取 `0.98`（藏进内部）即可。重合面是布尔的头号非流形来源。

## 5. 两个等栅格椭球相交 = 一圈重复顶点

- `uv_sphere(subdivisions=n)` 有经纬栅格，两个同档椭球的交线正好压在细分
  顶点上，引擎沿交线吐"同位置双顶点"（26 个，间距 ≤2e-6 mm）。
- 用 `icosphere(subdivisions=4)`：无极点无栅格，交线落在三角形内部，干净。

## 6. 导出前统一 merge_vertices

- 布尔经常留"同位置双顶点"对儿：按索引看 2-流形，3MF/STL 一进一出就变
  4 边面，切片软件报非流形。
- `parts = [(nm, col, solidify(m))]`，`solidify = copy + merge_vertices()`。

## 7. 短弧不要用链式胶囊

- 弧长 6.1mm / 管半径 0.6mm：分段弦长 0.25mm，`caps()` 把每段压成近"球"，
  26 个重度重叠球求并 → 808 个重复点。
- 用**圆环段**：torus 转进目标平面 + 两把过轴切刀求交，一次成型。
- 坑：torus `major_sections` 别取 72——切角落在段栅格上会穿过细分顶点。
  取 64 / 96。

## 8. "尖底 + 凹腔" = 掏空

- 心形 cone 尖底 + 从底尖往上挖深腔 → 锥尖段壁厚趋 0，件实际只靠一圈
  越来越薄的壁挂住，和座面零接触（bbox 看着正常）。
- 尖底件挖腔前，先把底部改成**平底缘或圆根**，让座面有实体可坐。

## 9. 验收只认三个数，不认索引

```python
# ① 顶点对账（防 k² / 共面类 bug）
assert np.allclose(mesh.vertices.max(axis=0), 解析式极值)
# ② 双向 contains（防过盈）
assert not body.contains(heart.vertices).any()
assert not heart.contains(body.vertices).any()
# ③ 3MF 往返后复查
reloaded = trimesh.load(path)  # nonmanifold_edges 必须仍为 0
```

## 10. `merge_vertices()` 会**制造**非流形，不是只清理

- **症状**：旋转体烛身 `wt=True / 坏边 0 / euler=2`，调一次
  `m.merge_vertices()` 之后变成 `wt=False / 48 条坏边 / euler=26`，三角形数量没变。
- **根因**：默认容差会把两张**本该分开**的曲面片焊在一起（相切区、高密度
  三角网格上的近邻点、布尔接缝两侧的顶点）。
- **修法**：合并前先记状态，只在"合完仍 watertight 且坏边为 0"时才采用，
  否则保留原件。别把 `solidify()` 写成无脑 merge。

```python
def solidify(m):
    base = m.copy()
    if base.is_watertight and _bad_edges(base) == 0:
        return base
    cand = m.copy(); cand.merge_vertices()
    return cand if cand.is_watertight and _bad_edges(cand) == 0 else base
```

## 11. `creation.revolve` 的轮廓不能有相邻重合点

- **症状**：烛身旋转体（底圆角→侧壁→顶圆角→熔池）接缝上一圈 48 条非流形边。
- **根因**：轮廓是"分段拼"出来的，侧壁终点 `(rt, h-rf)` 与顶圆角起点完全相同、
  熔池起点与顶圆角终点相同。重合顶点在旋转后沿接缝变成缝。
- **修法**：拼完先去重（相邻点距离 < 1e-6 丢掉），再 revolve。

## 12. 平面截球冠 = 一圈薄刃；要锥截

- **症状**：脸片用"外壳-内壳 ∩ y>=const"做球冠，边界在渲染色上出两个尖角、
  打印出来是一圈 0.1mm 毛边。
- **根因**：平面与球面在交线上的夹角是常数但很斜（球冠半角 42° 时切面与
  曲面只差 42°），壳厚 0.55mm 就被斜切成刀口。
- **修法**：用**顶点在球心、母线与轴夹角 = 球冠半角**的锥去截，交线处锥面
  与球面近乎垂直，边界是一条直角台阶。锥可以用
  `frustum(0.05, L*tan(θ), L)` 绕 X 转 -90° 做成沿 +Y 的锥。

## 13. 身体轮廓别用"圆柱 + 倒角环刀 + 卷边圆管"拼

- 拼出来的烛身一圈一圈棱线，读起来是罐子/管件（实测前后三版都被说"像罐子"）。
- 用**旋转体轮廓一次成型**：底圆角 → 收分侧壁 → 顶圆角 → 熔池，圆角是轮廓
  的一部分而不是布尔出来的，silhouette 干净。

## 14. "围住脸的一整圈卷边"会读成罐盖/围兜

- 整圈（212°）卷边包住脸 → 像罐子的口沿或围兜；只卷**上半圈**（≈176°）
  才是兜帽帽檐。差的就是下半圈那一截。

## 15. 拿照片当参考？先 de-roll，再谈"左右不对称"

- **症状**：用户说"腮红左边和右边不一样"，照照片建出来还是不像；或者反过来，
  把相机倾斜当成了设计不对称，脸建歪了。
- **根因**：手持拍摄的照片几乎总有滚转（实测一张玩偶照滚了 7°：右眼比左眼
  低 24px）。滚转会**制造**垂直方向的假不对称——眼下 7mm 的点能被搬走 2.5mm。
- **修法**：
  1. 用双眼中心连线求滚转角 `ρ = atan2(Δy, Δx)`，全图反旋 `-ρ` 后再测量；
  2. **验证换算链**：de-roll 后两眼应对称落回 `(±d/2, 同一高度)`，且与模型里
     已确认的参数（如 EYE_DX/DZ）吻合——对得上才敢用后面的数；
  3. 建模建的是"摆正后的脸"，不是照片的倾斜样子（除非用户明确要复刻倾斜）。
- 换算尺度用**瞳距**（照片瞳距 px ÷ 模型瞳距 mm = px/mm），别用包围盒。

## 16. 跨区域比大小，阈值必须逐区域自适应

- **症状**：同一张脸上左右两块腮红，测出来面积差 28%，以为是不对称设计。
- **根因**：单侧光。右脸在阴影里，全局饱和度/亮度阈值会把右腮红少算一大块。
- **修法**：每个特征各自取**局部背景统计**定阈值（如 `sat < 该侧脸饱和度中值
  × 0.62`），或者直接用差值图（`lum - gaussian(lum, σ)`）找细线件。
  本次实测：全局阈值下左 12311 / 右 9599（1.28 倍），局部阈值下
  11599 / 8705（1.33 倍）——差值是真的，但量级只有局部阈值可信。

## 17. `arc_mesh(radius, tube, span)` 的 tube 是**半径**

- 直径 = 2×tube。曾经按"线粗 0.6"传 `tube=0.6`，实际画出 1.2mm 粗的鼻子，
  比参考照片粗一倍，用户直接说"没那么粗"。
- 细线件（眉/鼻/嘴）对照照片时先算好直径再传；照片里刺绣线一般 0.3-0.6mm 粗。

## 18. 改全局轮廓参数（收分→等直径）时，把新值取在"关键特征高度的原值"上

- **症状**：用户说"蜡烛一般上下一样粗，你这个怎么下面粗一些变圆锥形了"。
  直接把 `CYL_R_BOT/CYL_R_TOP` 从 20/16.8 拍成 20/20 或 16.8/16.8 都能改对，
  但直径一换，**所有依赖烛体半径的派生几何**（脸凸包与侧壁的交线、桃脸边界、
  按 `cyl_r_at(z)` 贴脸的五官基准面）全部要重算重验，回归面大到不可控。
- **修法**：新直径 = 原变半径轮廓在**关键特征所在高度**的半径。收分
  20→16.8 在脸高 z=42 处恰好是 18.4，等直径取 18.4：脸高处的半径一毫米
  都没变，下游几何零改动，只有侧壁从斜的变直的。
- **验证**：改动前后**逐件对比 bbox extents**（桃脸/眼/腮红/眉/鼻/嘴各件的
  extents 数组应逐项一致），一致才说明真的只有目标件变了；再跑水密/非流形/
  euler 三件套。

## 19. 细于 ~0.5mm 的特征：切片器整盘拒绝，报错零信息量

- **症状**：整盘 `Failed slicing the model. Please verify the slicing of all
  plates`——不说是哪件、不说什么错。实测：Ø0.44 的弧管细条失败，
  Ø0.50 通过；0.4 喷嘴 / 0.42 线宽 / 0.2 层高下阈值约 **1.15×线宽**。
  任何"每层只剩一根线宽"的细条（细管、细描边、薄壳壁）都在危险区。
- **根因**：一层里放不下两条墙线，薄壁识别又盖不住这种尺寸，直接判错。
  闭合环（如 0.48mm 薄壳的一圈 rim）比开放细条耐一些，但别赌。
- **修法**：细条管粗/壁厚加到 ≥0.55mm（留 10% 余量防切片器版本漂移）。
  照片上的 0.35mm 刺绣线打不出来，加粗 0.2mm 在脸上不可见——**可打印性
  赢照片保真**。
- **定位方法**（混在整盘里查不出凶手）：写一根 `cylinder(radius=d/2)` 的
  直径阶梯（0.44/0.50/0.60/0.64），逐根直切，找红线；再逐件单切门禁
  （`slice_gate.py`），**别等烘焙才发现**。

## 20. bake_project 的 geo_src 快照坑 + CLI 单例锁假失败

- **geo_src 快照**：`bake_project.py` 第一次烤某个文件时把它复制到
  `<目录>/geo_src/`，**以后永远用那份快照**。改过模型重导出了盘文件，
  再烤还是旧几何——症状是"改了没用/修好的bug还在"，极其误导。
  **改模型后必须删 geo_src 再烤。**
- **CLI 单例锁假失败**：Bambu CLI 切完不退出。批量直切不杀进程组的话，
  后面的实例撞锁，同样报 `Failed slicing the model`——**假失败**。
  纪律：轮询产出文件 → 等 result.json 落盘 → `os.killpg`。
  反过来，只看到 `Initializing StaticPrintConfigs` 也不是成功标志
  （见 weigh_3mf.py 文档）。

## 21. 测 3mf 孔位只凭单层截面 + 顶点编辑后不复测 = 空操作修复

- **症状**：报告"已把卡位 Ø56.47 改到 Ø57.0"，用户打出来"跟原来一样"
  照样卡。复盘：编辑带取 r 27.9–28.9，而内壁实际在 **r 27.78–27.99**
  （低于带下界）——内壁一个顶点都没动，只蹭到外壁几个顶点（体积差
  16.8mm³，当时就该警觉）。
- **根因一：单层单次截面读数不可信。** 面心半径桶会把水平面/竖直面混在
  一起；带拔模的环壁在全高度上内径是变的（27.78→27.99）。正确测法：
  **全高度半径-z 扫描，且只留近竖直面**（|face_normals.z|<0.35），
  逐层报 r_min/r_max，才能同时看到内壁、外壁、入口 fillet。
- **根因二：编辑后不复测。** 顶点编辑（径向外移）最大的风险是**带没圈中
  目标面**。纪律：改完立刻用同一套测量脚本复测目标表面，确认数值真的到了
  目标半径；再看体积差量级是否合理（改 Ø56→Ø58 的 4mm 高环应该是
  数百 mm³ 级，不是 16.8）。
- **根因三：没有实物标尺。** 用户手拍图（无标尺+透视）量不出配件直径。
  **模型自带的商品图是最佳标尺**：正俯视封面图 + 几何已知外径（如整机
  Ø73）→ 反算配件实测直径。这次就是靠它量出线头 ~Ø57，推翻"Ø56"的假设。
- 顺带：3mf 的 item transform 决定板坐标≠局部坐标，测之前先平移回局部
  （否则 z 区间全部读错）。

## 22. 别信封面图当标尺 / 别用「面心半径聚类」找壁 —— 两层假象

> 接 #21。**#21 里那条「商品图是最佳标尺」事后被证伪**，务必按本条修正。

- **症状**：照 #21 用模型自带封面图反算配件外径，得 ~Ø57，于是把卡位从
  Ø55.6 扩到 Ø58.0；用户打出来反馈"还是大了点"。真值：**Ø55.5–55.9**。
  渲染图的分包线/描边/带壳测量让配件看起来大 1–2mm，**手绘图、渲染图、
  封面图都不能当 ±0.5mm 级的标尺**。
- **正确的尺寸锚点优先级**：
  1. **原设计模型的配合面尺寸** —— 设计师是照自己的真件画的，这就是实测值。
     本例：原内壁 r=27.75–27.90 → 盘就是 Ø55.5–55.8（且说明原设计是
     line-to-line，靠材料微让+PLA 低收缩塞进去；换 PETG 必卡）。
  2. **公开拆解报告的游标卡尺数据**（如充电头网 teardown）——第二独立源。
  3. 用户用卡尺实测（让他打两个字就有的数，比自己套 10 分钟图像分析划算）。
  4. 图片推算 —— 只能定性，别用来定 ±0.5mm 的配合。
- **别用「面心半径 + |nz|<0.35 聚类」去找壁**：这样会把别的特征（孔洞、
  走线槽、异形槽）的竖直面一并抓进来，凭空造出一堵不存在的"外壁"。
  本例我据此判"内壁 27.8 / 外壁 28.6，壁厚 0.9mm"，还专门给锥面让位
  1.2mm —— **全是针对幻影做的无用功**。
- **找壁的正确做法：逐层射线法求实体径向区间**。对每层 z 做水平截面，
  取所有线段，沿某个方位角从原点发射一条射线，解出全部交点距离 t 并排序，
  两两成对即实体区间（`radial.py`）。输出形如：
  ```
  az=90  z=2.0 → 27.78–32.41    z=4.0 → 27.82–29.68
          z=5.0 → 27.89–28.99   z=5.25 → 28.15–28.61
  ```
  一眼看出：内壁之外是**一整片实心斜锥**（有的是料），根本不存在薄壁。
  于是只需推内壁，外壁/锥面都不用动。多取 2–3 个方位角交叉验证。
- **推论**：改孔径前先确认外侧有没有余量。有余量就只推内壁（一次单变量编辑），
  没余量才需要连外壁一起外移 + 给相邻面让位。

## 23. 截面环「看起来闭合」，polygonize 却静默丢环 —— 面积虚小一个数量级

- **症状**：细枝件逐层量截面，总面积在不可能的地方塌掉（本例躯干高度上只有 0.4 mm²）。
  用 KD-tree 查端点配对，**100 % 都配上了**，看着完全正常。
- **根因**：`polygonize` 要求相邻线段端点**坐标完全相同**。三角面求交算出来的同一
  交点，在两侧三角面里差 1e-5～1e-6；判「未闭合链」后**整条环被丢掉，不报错**。
- **修法**：先节点化再成面——
  ```python
  lines = [LineString(np.round(s, 5)) for s in segs]      # 先圆整
  polys = list(polygonize(unary_union(lines)))            # 再 union 打断/接合
  ```
  修完本例截面总面积回到 20–80 mm²，与体积/高度（3754/100 ≈ 37 mm²）自洽。
- **自检**：任何「逐层面积」都要过一次**体积守恒**——`Σ(层面积×层距) ≈ 网格体积`。
  差一个量级就是丢环，不是模型有问题。
- **等价直径**：`4A/P`（近圆截面 ≈ Ø）。别用 `2A/P`，那是半径。
- 细枝件的完整量法与判据见 `organic-thin.md`。
